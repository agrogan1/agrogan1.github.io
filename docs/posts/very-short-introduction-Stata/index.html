TipStata Is Very Intuitive

The basic philosophy of Stata—“Stata in one sentence”—is:

do_something to_variable(s), options

Often it is not necessary to use any options since the authors of Stata have done such a good job of creating an intuitive language, and of thinking about the defaults.

Commands that you actually type are represented in monospace font. x and y refer to variables in your data.

  1. lookfor thing looks for any variable with thing in the variable name or variable label. lookfor somethingelse looks for any variable with somethingelse in the variable name or variable label. It is often useful to lookfor abbreviations e.g. lookfor anx instead of lookfor anxiety.↩︎

  2. describe, short will give you quick summary information about the data including sample size.↩︎

  3. After the , the row and col options can be helpful to generate row and column percentages.↩︎

  4. After the , the item option will estimate the increase in alpha if the particular item were removed.↩︎

  5. It is usually best practice, but not required, to recode values of a variable (e.g. x) into a new variable (e.g. xR), leaving the original variable untouched.↩︎

  6. This example is using probability weights or sampling weights. Stata has other kinds of weights. See help weight for more information. For more complex survey designs see help svy.↩︎

  7. Here we need to use the , or option to ask for odds ratios instead of logit coefficients.↩︎

  9. Here we need to use the , rr option to ask for risk ratios instead of logit coefficients.↩︎
